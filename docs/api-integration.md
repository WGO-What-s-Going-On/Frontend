# 백엔드 연동 기록

> **백엔드에 요청할 것은 1~4번입니다.** 5번은 어느 쪽에 맞출지 같이 정할 것, 6번은 참고용입니다.
>
> - **1번:** 이게 없으면 연동을 더 진행할 수 없음 (가장 급함)
> - **2번:** 지금 화면을 그리는 데 필요한데 응답에 없는 필드
> - **3번:** 화면은 있는데 API가 없는 기능
> - **4번:** 정해 주셔야 하는 값 · 설정
>
> 표 안의 API 경로 · 필드 이름(`authorNickname` 등)은 **프론트가 제안하는 예시**입니다. 백엔드 쪽 이름 규칙에 맞게 바꾸셔도 됩니다.

- Swagger: https://d35lxgeutzw8c6.cloudfront.net/docs
- 기준: 2026-10-28 staging 직접 호출 결과
- 같은 내용의 노션 페이지: WGO 백엔드 연동 기록 (이 문서를 고치면 노션도 같이 고친다)
- 프론트 실행: `cp .env.example .env.local` → `npm run dev -- --port 5173 --strictPort`. 에러가 나면 브라우저 콘솔의 `[API] 메서드 경로 → 상태 코드: 메시지 (requestId)`를 아래에 옮긴다 (토큰은 남기지 않는다)

## 1. 연동을 막고 있는 것 (가장 급함)

| # | 요청 | 확인 결과 |
| --- | --- | --- |
| 1-1 | 게시글 계열 API 503 해제 | `/posts/*`, `/location`, `/notifications/*`, `/posts/media/*` 전부 `503 Authentication integration unavailable` |
| 1-2 | 주변 게시글 목록 공개 API | 공개 API에 없음. `/internal/v1/posts/nearby` 내부용만 있음 |
| 1-3 | 카카오 REST API 키 + redirect URI 등록 | 로그인 코드는 연결 완료, 키가 없어 실제 로그인 확인 불가 |

- **1-1:** 글 작성 · 상세 · 댓글 · 공감 · 투표 · 위치 · 알림 · 사진 업로드가 전부 여기 걸려 있음. 프론트는 이 API들을 부르는 코드를 준비해 두었고(`src/api/posts.ts`), 풀리면 바로 화면에 연결함.
- **1-2:** 앱 첫 화면(지도 핀)과 게시판 목록이 "내 주변 글 목록"으로 그려짐. 이게 없으면 사용자가 글을 볼 방법이 없음.
  - 제안 예시: `GET /api/v1/posts/nearby?latitude=&longitude=&radiusM=&cursor=&limit=`
  - 응답 항목: 게시글 상세와 같은 필드 + 거리(`distanceM`)
  - 화면에서 거리순 · 최신순 정렬, 카테고리 필터를 씀
- **1-3:** 프론트 콜백 주소는 `http://localhost:5173/auth/kakao/callback`. 백엔드 `KAKAO_REDIRECT_URI`와 Kakao Developers 등록 주소 둘 다 이 주소로.

## 2. 응답에 추가가 필요한 필드

| # | API | 필드 (제안 예시) | 쓰이는 화면 |
| --- | --- | --- | --- |
| 2-1 | 게시글 상세 · 목록 | `authorNickname`, `anonymous` | 게시글 작성자 이름 |
| 2-2 | 게시글 상세 · 목록 | `reactionCounts: { CURIOUS, STILL_HAPPENING, HELPFUL, ENDED }` | 게시글 반응 4가지 숫자 |
| 2-3 | 게시글 상세 · 목록 | `myReaction` | 내가 누른 반응 표시 |
| 2-4 | 댓글 목록 | `authorNickname` | 댓글 작성자 이름 |
| 2-5 | 댓글 목록 | `myReaction` | 내가 누른 댓글 공감 표시 |
| 2-6 | 댓글 작성 · 목록 | `parentCommentId` | 답글(대댓글) |
| 2-7 | 게시글 작성 요청 | `anonymous` | 글 쓸 때 닉네임 / 익명 선택 |

- 지금 응답에는 작성자가 `authorId` 숫자로만 와서, 화면에 이름을 띄울 수 없음.
- 반응은 `counters.reactionCount` 합계만 와서, "궁금해요 18 · 진행 중 32"처럼 종류별로 나눠 보여줄 수 없음.
- 내가 누른 반응이 없으면 다시 눌러 취소하거나 다른 반응으로 옮기는 동작을 화면이 판단할 수 없음.
- 답글은 지금 화면에 있는 기능이라 지원 여부를 정해야 함. 지원하지 않으면 프론트에서 답글 기능을 뺌.

## 3. 새로 필요한 API

| # | 기능 | 쓰이는 화면 | 프론트 의견 우선순위 |
| --- | --- | --- | --- |
| 3-1 | 게시판 직접 종료 · 종료 해제 | 게시글 ⋯ → 종료, 마이 → 최근 활동 → 종료 해제 | 높음 |
| 3-2 | 신고 (게시글 · 댓글, 사유 포함) | 게시글 · 댓글 ⋯ → 신고 | 높음 |
| 3-3 | 차단 · 차단 목록 | 게시글 · 댓글 ⋯ → 차단 | 높음 |
| 3-4 | 게시글 수정 | 게시글 ⋯ → 수정 | 보통 |
| 3-5 | 게시글 검색 | 게시판 → 검색 | 보통 |
| 3-6 | 게시판별 알림 켜기 · 끄기 | 게시판 · 피드의 종 아이콘 | 보통 |
| 3-7 | 알림 종류별 수신 설정 | 마이 → 알림 설정 | 보통 |
| 3-8 | 최근 활동 목록 | 마이 → 최근 활동 | 낮음 |
| 3-9 | 칭호 · 활동 점수 | 활동 탭 → 뱃지 | 낮음 |
| 3-10 | 지역 랭킹 | 활동 탭 → 랭킹 | 낮음 |

- **우선순위 기준:** 신고 · 차단 · 종료는 서비스 운영에 꼭 필요해서 높음. 칭호 · 랭킹은 이번 회의에서 새로 정한 기획이라 낮음.
- **3-1 종료:** 지금 서버는 `expiresAt` 자동 만료만 있음. 작성자가 직접 끝내고 다시 여는 기능이 화면에 있음.
- **3-9 칭호:** 소식통 → 리포터 → 특파원 → 천리안 4단계. 필요한 값은 참여 횟수, 받은 '맞아요' 수, 댓글 투표 대표 의견 점수, 현재 칭호.
- **3-10 랭킹:** 천리안 사용자의 지역(동)별 순위와 내 순위.

## 4. 정해 주셔야 하는 값 · 설정

| # | 항목 | 지금 상태 | 요청 |
| --- | --- | --- | --- |
| 4-1 | 카테고리 코드 | 서버 예시는 `INCIDENT`, `CROWD` | 화면 카테고리 4개의 코드값 확정 |
| 4-2 | 약관 데이터 | `GET /terms` → `{"terms":[]}` | staging에 필수 약관 3개 등록, 약관 `code` 이름 공유 |
| 4-3 | 알림 목록 응답 형식 | Swagger의 `GET /notifications` 응답이 비어 있음 | 응답 형식 공유 |
| 4-4 | WebSocket 브라우저 인증 | 브라우저 WebSocket은 Authorization 헤더를 못 붙임 | 쿠키 방식 또는 접속 티켓 방식 결정 |
| 4-5 | iOS 앱 카카오 로그인 복귀 | 앱 안에서는 localhost로 못 돌아옴 | 앱용 redirect(딥링크) 방식. 웹 연동 끝난 뒤 |

- **4-1:** 화면 카테고리는 긴급 사고 · 도움 요청 · 동네 소식 · 일상 불편 4개. 프론트는 임시로 `EMERGENCY` · `HELP` · `NEWS` · `ETC`를 보내고 있어서(`src/api/posts.ts`), 확정되면 바꿈.
- **4-2:** 동의 API는 약관 ID가 최소 1개 있어야 해서, 지금은 약관 동의를 저장할 수 없음(프론트는 목록이 비면 동의 요청을 건너뜀). 필수 약관은 서비스 이용 · 개인정보 처리 · 위치정보 이용 3개.

## 5. 같이 정할 것 (규칙 차이)

| # | 항목 | 프론트 | 백엔드 |
| --- | --- | --- | --- |
| 5-1 | 닉네임 | 2~12자, 한글 · 영문 · 숫자, 금칙어 확인 | 중복 확인은 1글자도 사용 가능, `PATCH /users/me` 최대 30자 |
| 5-2 | 비슷한 글 범위 | 공개 범위 150 · 250 · 350m | `/posts/similar`는 150m · 최근 24시간 고정 |

- **5-1:** 프론트가 더 엄격해서 당장 문제는 없음. 서버에도 같은 규칙을 둘지만 정하면 됨.
- **5-2:** 250 · 350m로 올린 글도 비슷한 글 비교에 넣을지 정해야 함.

## 6. 참고 (요청 아님)

**프론트가 보내는 방식**

- 글 제목: 작성 화면에 제목 칸이 없어서 본문 첫 문장을 제목으로 만들어 보냄
- 공개 범위: `radiusM`에 150 · 250 · 350 그대로 보냄
- 공감 종류: 게시글 `CURIOUS` · `STILL_HAPPENING` · `HELPFUL` · `ENDED`, 댓글 `HELPFUL` · `AGREE` · `DIFFERENT`

**동작 확인된 것**

- localhost:5173 CORS 정상, 닉네임 중복 확인 · 약관 조회 200
- 카카오 로그인에 잘못된 코드를 보내면 401로 정상 거절
