# WGO Design

내 주변 150m에서 지금 일어나는 일을 빠르게 읽고 답하는 앱. 화면의 주인공은 사건과 사람들의 글이고, UI는 그 뒤로 물러난다.

참고: Anthropic frontend-design skill, Vercel Web Interface Guidelines, awesome-design-md(Uber, Airbnb DESIGN.md). 그대로 베끼지 않고 아래 기준으로 재해석했다.

## 1. 색은 의미가 있을 때만

파랑은 "나와 내 행동"에만 쓴다. 사건의 종류는 카테고리 색이 말한다. 나머지는 무채색이다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--c-canvas` | `#ffffff` | 화면 바탕 |
| `--c-surface` | `#f3f4f6` | 입력창, 필터, 설정 묶음 같은 낮은 면 |
| `--c-line` | `#e7e9ed` | 목록 구분선 |
| `--c-ink` | `#17191e` | 제목, 본문 강조 |
| `--c-body` | `#474c55` | 본문 |
| `--c-mute` | `#8b919c` | 시간, 거리, 조회 같은 보조 정보 |
| `--c-accent` | `#2b5ce6` | 내 위치, 선택된 필터, 주 버튼, 읽지 않음 |
| `--c-urgent` | `#e5484d` | 긴급 사고 |
| `--c-help` | `#e8890c` | 도움 요청 |
| `--c-news` | `#2f9a6a` | 동네 소식 |
| `--c-daily` | `#7c8290` | 일상 불편 |

- 라벤더, 보라, 그라데이션 배경 금지.
- 회색은 위 세 단계(ink, body, mute)만. 비슷한 회색을 새로 만들지 않는다.
- 색만으로 상태를 전달하지 않는다. 카테고리는 점 + 글자로 표시한다.
- 카카오 로그인 버튼은 카카오 공식 가이드 색(`#FEE500`, 글자 85% 검정)을 따른다.

## 2. 글자

Pretendard 하나만 쓴다. 숫자는 `tabular-nums`.

| 이름 | 크기/행간/굵기 | 쓰임 |
|---|---|---|
| title | 24/32/700 | 화면 제목 |
| headline | 20/28/700 | 게시글 상세 제목 |
| subject | 16/24/600 | 목록 제목, 댓글 작성자 |
| body | 15/24/400 | 본문, 댓글 |
| meta | 13/18/400 | 시간, 거리, 조회, 댓글 수 |
| caption | 12/16/600 | 카테고리, 배지, 하단 메뉴 |

- 12px 미만 금지. 입력창은 16px(iOS 확대 방지).
- 전부 대문자 라벨, 제목 속 한 단어만 색 바꾸기 금지.

## 3. 면과 깊이

- 목록은 카드가 아니라 구분선이 있는 행이다. 카드 안에 카드 금지.
- 기본은 평면. 그림자는 화면 위에 떠 있는 것(작성 버튼, 시트, 팝업, 지도 핀)에만.
- radius: 입력과 버튼 12, 필터 칩 999, 시트 상단 20, 팝업 14. 행에는 radius 없음.
- 아이콘 버튼은 테두리 없는 40px 터치 영역. 아이콘이 글보다 강해 보이면 안 된다.

## 4. 간격

4의 배수: 4, 8, 12, 16, 20, 24, 32. 화면 좌우 여백 20.

## 5. 움직임

- 사용자의 행동에 대한 응답에만. 160ms 안팎, `transform`/`opacity`만.
- 로그인 화면의 지도 연출 하나만 예외로 자동 재생.
- `prefers-reduced-motion`이면 끈다.

## 6. 금지 목록

- 의미 없는 장식 원, 반짝임, 글로우, 파란 그림자
- 모든 요소에 같은 둥근 카드 + 같은 회색 그림자
- 장식용 배지, 이모지, 쓸모없는 화살표
- 같은 정보 두 번 표시
- 마케팅 문구("스마트한", "쉽고 빠르게")
