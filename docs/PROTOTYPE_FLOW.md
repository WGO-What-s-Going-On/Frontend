# WGO 인터랙티브 프로토타입 흐름

현재 브랜치: `feat/prd-interactive-prototype`

백엔드 연결 전 PRD의 P0 기능 흐름을 검증하기 위한 메모리 기반 프로토타입이다. 새로고침하면 데이터가 초기화된다.

## 1. 인증과 위치

1. 카카오로 계속하기를 누른다.
2. 위치 권한을 허용하거나 열람 모드로 시작한다.
3. 지도 하단의 프로토타입 스위치로 150m 안/밖 상태를 바꾼다.
4. 범위 밖에서는 게시판 작성, 댓글, 반응이 제한되는지 확인한다.

## 2. 지도와 게시판 탐색

1. 지도 핀을 눌러 게시판 상세로 이동한다.
2. 게시판에서 카테고리 필터와 거리순/최신순/활성순 정렬을 바꾼다.
3. 검색 화면에서 키워드와 열람 범위를 바꾼다.

## 3. 게시판 CRUD

1. 작성 탭에서 카테고리를 선택한다.
2. 제목, 설명, 선택적 사진과 투표를 입력해 게시판을 만든다.
3. 내가 만든 게시판의 더보기에서 수정, 종료, 삭제를 실행한다.
4. 종료 게시판에서 새 댓글과 반응이 제한되는지 확인한다.

## 4. 댓글과 반응

1. 게시글에 저도 궁금해요/지금도 그래요/도움 됐어요/이제 끝났어요 반응을 남긴다.
2. 댓글을 작성하고 기존 댓글에 답글을 남긴다.
3. 댓글에 도움돼요/맞아요/정보가 달라요 반응을 남긴다.
4. 내가 쓴 댓글은 삭제하고 다른 사용자의 댓글은 신고 또는 차단한다.

## 5. 알림과 마이페이지

1. 알림을 개별로 읽거나 모두 읽음 처리한다.
2. 프로필을 수정한다.
3. 최근 활동에서 내가 만든/참여한/공감한 게시판을 필터링한다.
4. 알림 설정, 로그아웃, 회원 탈퇴 흐름을 확인한다.

## 6. 신고와 운영

1. 다른 사용자의 게시글 또는 댓글을 신고한다.
2. 마이페이지의 프로토타입 관리자 화면으로 이동한다.
3. 신고를 문제없음 또는 숨김 처리한다.
4. 숨김 처리된 게시글이 일반 목록에서 제외되는지 확인한다.
